# 旗影 / Flag Lab

一个无需构建步骤的静态网页：Three.js + EXR 天体球 + 基于 Verlet 积分和结构/剪切/弯曲约束的实时布料模拟。

## 运行

由于浏览器会限制 `file://` 页面读取 EXR 和 ES modules，建议从此目录启动一个静态服务器：

```powershell
python -m http.server 4173
```

然后打开 <http://127.0.0.1:4173/>。

首次加载需要访问 CDN 获取 Three.js 模块；EXR 背景从 `exr/` 目录读取。页面内置该目录下的 9 个 EXR 选项，也支持选择自定义 `.exr` 文件替换天体球。

## 功能

- 上传 SVG、PNG、JPG、WEBP 或 GIF 作为旗帜纹理
- 真实时间布料积分：Verlet 速度、重力、阵风扰动、结构/剪切/弯曲约束与底部碰撞
- 调节风速、阵风扰动、自动风向
- 调节水平角度、垂直角度、摄像机距离，并支持拖拽环绕和滚轮缩放
- 鼠标右键按住拖动可在 3D 空间平移摄像机，支持背景整体旋转
- 切换目录中的 EXR 天体球或上传自定义 EXR
